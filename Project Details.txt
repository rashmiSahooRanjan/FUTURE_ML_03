# ANTIGRAVITY AI — COMPLETE PROJECT DEVELOPMENT PROMPT

## Project: TalentRank AI
**AI-Powered Resume Intelligence & Candidate Ranking Platform**

### 1. Project Overview

Build a complete, professional, production-style Resume Screening and Candidate Ranking System using Python, Machine Learning, Natural Language Processing (NLP), and Streamlit.

The application should help recruiters and HR teams analyze multiple resumes against a given job description.

The system should automatically:

1. Upload and read multiple resumes.
2. Extract resume text from PDF, DOCX, and TXT files.
3. Clean and preprocess resume text.
4. Extract technical and professional skills.
5. Analyze job descriptions.
6. Calculate candidate-job compatibility scores.
7. Rank candidates from highest to lowest match.
8. Identify matching and missing skills.
9. Generate individual candidate analysis reports.
10. Display recruitment analytics through an interactive dashboard.

**Important:** This must be a fully functional application, not just a frontend UI or static dashboard. Every button, upload component, filter, calculation, chart, and report-generation feature must work.

## 11. Machine Learning and Candidate Matching Engine

This is the core module of the application.

Implement a hybrid resume-matching approach using:

1. TF-IDF Vectorization.
2. Cosine Similarity.
3. Skill Matching.
4. Experience Matching.
5. Education Matching.
6. Keyword Relevance.

### A. TF-IDF Vectorization

Use Scikit-learn's TfidfVectorizer to convert resume text and job description text into numerical vectors.

Compare the vectors using cosine similarity.

Formula:

Cosine Similarity = (A · B) / (||A|| × ||B||)

Convert the similarity into a percentage.

### B. Skill Matching Score

Calculate the percentage of required skills found in the resume.

Formula:

Skill Match Score = (Matched Required Skills / Total Required Skills) × 100

Also calculate preferred skill matching separately.

### C. Experience Matching Score

Compare the candidate's extracted experience with the minimum required experience.

Use transparent rules:
- Meets or exceeds the requirement: 100.
- Slightly below the requirement: proportional score.
- No relevant experience found: 0 or mark as unknown, depending on available evidence.

Do not assume that missing experience information means zero years of experience.

### D. Education Matching Score

Compare the candidate's education against the job requirement.

Use configurable rules and mark unavailable education information as unknown.

### E. Keyword Relevance Score

Calculate how many relevant job-description keywords appear in the resume.

### F. Final Match Score

Use the following initial weighted scoring model:

| Component | Weight |
|---|---:|
| Required Skill Match | 40% |
| TF-IDF Similarity | 25% |
| Preferred Skill Match | 15% |
| Experience Match | 10% |
| Education Match | 5% |
| Keyword Relevance | 5% |
| Total | 100% |

Formula:

Final Score =

(Required Skills × 0.40) +
(TF-IDF Similarity × 0.25) +
(Preferred Skills × 0.15) +
(Experience × 0.10) +
(Education × 0.05) +
(Keyword Relevance × 0.05)

All component scores must be between 0 and 100.

Important scoring rules:
- Allow recruiters to change weights.
- Validate that all weights total 100%.
- Normalize scores when information is genuinely unavailable.
- Clearly show when a score is based on incomplete information.
- Missing information must not automatically be interpreted as a negative qualification.
- Do not claim that the model predicts job performance.
- Show the contribution of each component to the final score.

### G. Candidate Ranking

After calculating scores, rank candidates in descending order.

Display:

- Rank
- Candidate name
- Resume filename
- Job role
- Final match score
- Required skills matched
- Missing required skills
- Experience
- Screening recommendation

Use these recommendation labels:

- Strong Match
- Good Match
- Partial Match
- Needs Review

These are decision-support labels, not automatic hiring or rejection decisions.
